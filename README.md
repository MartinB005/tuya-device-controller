# Tuya Device Controller

A lightweight Windows taskbar application designed to interact with and control Tuya-compatible smart devices.

---

## 🚀 Features

* **Device Discovery:** Detect or configure Tuya devices active connected with your account
* **Status Monitoring:** Real-time tracking of device states and attributes.
* **Direct Control:** Send commands to control device states (on/off, brightness, custom Data Points).


## Installation
Just download and run exe file from bin/Debug
Or
Build the project on your own
```bash
   git clone [https://github.com/MartinB005/tuya-device-controller.git](https://github.com/MartinB005/tuya-device-controller.git)
   cd tuya-device-controller
```
